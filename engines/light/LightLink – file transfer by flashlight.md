# LightLink

Send a file by blinking light. Receive it with the camera. No internet, no cable.

Point the flashlight (or screen) straight at the other device’s camera, 10–30 cm away, in a dim room. The file repeats in a loop until the receiver has every packet, so it’s fine to start late or lose a few.
